# Gerenciar tokens de provedores externos no backend

O backend valida o token de identidade e o código de autorização recebidos do aplicativo, troca o código diretamente com o provedor e guarda o refresh token retornado de forma criptografada. Segredos do provedor e a chave de criptografia existem somente na configuração segura do servidor, enquanto o aplicativo continua usando apenas os tokens emitidos pelo Yomora. O custo de proteger uma credencial adicional permite verificar o vínculo e revogar a autorização externa em desvínculos e exclusões de conta. Notificações válidas de revogação removem o vínculo e encerram todas as sessões Yomora; a Conta Yomora é preservada quando uma senha permanece ativa e excluída quando a identidade externa era seu único Método de acesso.
