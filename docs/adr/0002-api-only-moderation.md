# A moderação inicial é operada por endpoints administrativos

Nesta etapa, Moderadores acessam a Fila de moderação exclusivamente por endpoints administrativos protegidos da API. Escolhemos não criar um console web nem um modo administrativo no app iOS para entregar a revisão humana com menor superfície de interface e sem expor ferramentas internas aos leitores; uma interface operacional poderá ser adicionada quando o volume de Denúncias justificar esse investimento.
